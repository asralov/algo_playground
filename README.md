# 🚀 Algo Playground

Welcome to **Algo Playground**, an interactive web-based platform designed to make complex algorithms, data structures, and machine learning concepts easy to understand and fun to explore. 

Whether you are a student, a developer preparing for interviews, or just curious about how things work under the hood, Algo Playground offers hands-on visual simulations to bridge the gap between theory and execution.

---

## 🌟 Features & Projects

Explore a growing collection of visual, interactive projects:

### 🧠 AI & Machine Learning
* **Linear Regression:** An interactive supervised learning model. Plot custom or random points, tweak hyperparameters like learning rate and epochs, and watch gradient descent find the line of best fit in real-time.

### 🗺️ Algorithms
* **Pathfinding Visualizer:** Experience how algorithms like BFS, DFS, and A* find the shortest path or traverse a maze.
* **Sorting Visualizers:** * *General Sorting:* Watch algorithms (such as bubble sort) swap and slide into place step-by-step.
  * *Merge Sort:* Visualize the "Divide and Conquer" strategy in a recursive hill layout with speed controls.

### 🏗️ Data Structures
* **Trie Autocomplete Simulator:** Understand how predictive text systems and fast autocomplete suggestions work.
* **Binary Search Tree (BST):** See hierarchical data storage and watch real-time animations of insertions, searches, and complex node deletions.
* **Stack & Queue:** Interactive simulations of LIFO (Last-In, First-Out) and FIFO (First-In, First-Out) logic.
