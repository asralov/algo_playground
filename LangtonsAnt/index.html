WHEN CHAOS FINDS A RHYTHM

Predictable rules. Surprising patterns.

Langton’s Ant is deterministic: the same starting world always produces the same path. On a blank square grid, its wandering looks chaotic for around 10,000 steps. Then a repeating 104-step pattern appears, building a diagonal “highway” that continues indefinitely.

The hexagonal world explores a different rule: turn 60° right on light tiles and 60° left on green tiles. It is a variant, so the classic highway behavior does not apply. Both worlds use an unbounded grid; only the camera’s visible area is drawn.
