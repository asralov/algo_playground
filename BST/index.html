WHY THE SHAPE MATTERS

Same values. Different search costs.

Insert, search, and delete take O(h), where h is the tree height. A balanced shape has height O(log n); sorted insertions can produce a chain with height O(n). This tree does not automatically rebalance.

Leaf: remove it directly.

One child: promote that child.

Two children: replace the value with the smallest value in the right subtree, then remove that successor from its old position.

Inorder traversal returns values in ascending order. A single node has height 0.
