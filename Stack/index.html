      WHY A STACK?

      Think of a pile of plates.

      You place a new plate on top and take that plate off first. A stack follows the same rule: last in, first out.

      Push(value)Add a value above the current top.

      Pop()Remove and return the top value.

      Peek()Read the top value; leave every item in place.

      Used in undo history, function calls, and expression parsing. Pop and peek are O(1); array-backed push is amortized O(1). Index 0 is the bottom.
