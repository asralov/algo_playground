Logistic Regression (Classification)

What is Logistic Regression? Unlike linear regression, it is a classification algorithm. It maps continuous inputs to a probability between 0 and 1 using the Sigmoid Activation Function, finding a boundary line that separates two unique classes.

How to use: Select whether you want to drop Class 0 (Red) or Class 1 (Green) dots. Plot mixed points on the canvas, or let the tool generate them. Press Train Model to see the separating decision boundary organize itself in real-time.
